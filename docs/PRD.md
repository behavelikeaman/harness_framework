# PRD: viral-lens

## 목표
특정 유튜브 채널에서 유독 성과가 튄 영상을 찾아내고, 그 패턴을 근거로 다음에 만들 컨텐츠 기획안을 제안한다.

## 사용자
자기 채널이나 벤치마킹 대상 채널의 "왜 이 영상만 터졌는가"를 알고 싶은 유튜브 크리에이터 및 컨텐츠 기획자.

## 핵심 기능
1. **채널 분석** — 채널 핸들/URL/ID를 입력하면 최근 업로드 50개의 조회수·좋아요·댓글·길이를 수집한다.
2. **핫 컨텐츠 랭킹** — 채널 자체 중앙값 대비 성과 배수(performanceRatio), 참여율(engagementRate), 속도(velocity)를 합성한 viralScore로 영상을 정렬해 어떤 영상이 튀었는지 보여준다.
3. **AI 기획안 추천** — 상위 성과 영상의 제목·지표·태그 패턴을 Claude에 넘겨, 근거 영상을 명시한 새 컨텐츠 기획안 5개(제목·훅·포맷·근거)를 생성한다.

## MVP 제외 사항
- 로그인 / 계정 (누구나 채널을 입력해 조회)
- 데이터베이스 저장 및 분석 이력 (매 요청 시 재조회, 10분 메모리 캐시만)
- 다중 채널 비교 및 시계열 추이 그래프
- 경쟁 채널 검색 / 유사 영상 실물 검색 (`search.list` — quota 100 units)
- 영상 자막·썸네일 이미지 분석

## 디자인
- 다크모드 고정. 마케팅 랜딩이 아니라 매일 쓰는 도구형 대시보드
- 무채색 기반 + 데이터 시맨틱 색상만 포인트로 사용 (성과 상승 초록 / 하락 빨강 / 중립 회색). 브랜드 컬러 없음
